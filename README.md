# 🎬 Netflix Clone

A responsive Netflix UI Clone built using HTML, CSS, and JavaScript.  
This project is created for learning frontend development and improving UI/UX skills.

---

## 🚀 Features

- 🎥 Netflix-like homepage UI
- 📱 Fully responsive design (mobile, tablet, desktop)
- 🎞️ Movie banner & thumbnails layout
- 🎨 Smooth hover effects and modern UI
- ⚡ Fast and lightweight static website

---

## 🛠️ Tech Stack

- HTML5  
- CSS3  
- JavaScript
